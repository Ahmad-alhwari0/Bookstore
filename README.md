
# Bookstore & Reading Club

A JavaScript practice project developed as part of the Orange Coding Academy training.

## Project Description

This project includes JavaScript exercises that practice basic programming concepts such as:

* Variables and data types
* Operators and expressions
* User input using `prompt()`
* Output using `alert()` and `console.log()`
* If-else conditions
* Switch statements
* Functions
* Loops
* String manipulation

## Exercises

The project includes the following exercises:

* **Q1:** JavaScript expressions, operators, and data types
* **Q2:** Read and display a number
* **Q3:** Display two numbers in ascending order
* **Q4:** Find the larger of two numbers
* **Q5:** Calculate the sum of two numbers
* **Q6:** Convert numbers from 1–9 to their corresponding words
* **Q7:** Determine program eligibility based on age
* **Q8:** Toggle lowercase and uppercase letters
* **Q9:** Transform text into CamelCase
